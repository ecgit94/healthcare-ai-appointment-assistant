# Healthcare AI Appointment Assistant

## About This Project
This is my first AI agent development project.

The goal is to build a simple healthcare assistant that can help patients:
- Check upcoming appointments
- Request new appointments
- Retrieve basic appointment information

## Technologies I'm Learning
- APIs and HTTP requests
- JSON
- Git and GitHub
- AI agents and tool calling

## Project Goals
Understand how AI agents interact with external systems and how to design safe, reliable healthcare workflows.

## Status
Currently learning GitHub and API fundamentals.

Note: This project uses fictional patient information only.
## Planned Features

- Appointment cancellation
- Appointment rescheduling
- Patient identity verification
